# Areas Dashboard

The standing areas. This list is closed on purpose.

## All areas

```dataview
TABLE file.mtime AS "Last touched"
FROM "2. Areas"
WHERE type = "area"
SORT file.name ASC
```

## Least recently touched

Whatever sits at the top here is the area being neglected. That is the whole point of the view.

```dataview
TABLE file.mtime AS "Last touched"
FROM "2. Areas"
WHERE type = "area"
SORT file.mtime ASC
LIMIT 6
```

## Notes by area

```dataview
TABLE length(rows) AS "Notes"
FROM "3. Projects" OR "4. Resources"
WHERE area
GROUP BY area
SORT length(rows) DESC
```

## Untriaged tasks

Open tasks carrying no `#area` tag. No area view will ever surface these, which is why they get
their own list here.

Edit the tag names below to match your own areas.

```dataview
TASK
FROM "1. Journal" OR "3. Projects"
WHERE !completed AND text
  AND !contains(lower(text), "#family")
  AND !contains(lower(text), "#professional")
  AND !contains(lower(text), "#home")
  AND !contains(lower(text), "#discipline")
  AND !contains(lower(text), "#creation")
SORT file.name DESC
```
