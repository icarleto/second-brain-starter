# Home

The one note to open when you do not know where to start.

## Today

```dataview
LIST
FROM "1. Journal"
WHERE type = "daily"
SORT file.name DESC
LIMIT 3
```

## Top priorities

```dataview
TABLE priority AS "#", area AS "Area"
FROM "3. Projects"
WHERE type = "project" AND status = "active"
SORT priority ASC
LIMIT 5
```

## Needs attention

Projects nobody has touched in two weeks. Either they are stalled or they are finished and were
never closed, and both are worth knowing.

```dataview
TABLE area AS "Area", file.mtime AS "Last touched"
FROM "3. Projects"
WHERE type = "project" AND status = "active" AND file.mtime < date(today) - dur(14 days)
SORT file.mtime ASC
```

## Inbox

Anything sitting here has not been filed. It should be near empty.

```dataview
LIST
FROM "00. Inbox"
SORT file.mtime DESC
```
