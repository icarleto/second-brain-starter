# Journal Dashboard

## Unprocessed dailies

The queue. Ask Claude to process today's daily note and this empties itself.

If this list grows past a few days, the daily habit is slipping, which matters more than anything
else on any dashboard. The structure survives neglect. The habit does not.

```dataview
TABLE date AS "Date"
FROM "1. Journal"
WHERE type = "daily" AND processed != true
SORT date DESC
```

## Recently processed

```dataview
TABLE date AS "Date"
FROM "1. Journal"
WHERE type = "daily" AND processed = true
SORT date DESC
LIMIT 10
```

## Processed but still in the root folder

A processed daily older than today belongs in `1. Journal/Processed`. This catches the ones that
never made the trip.

```dataview
LIST
FROM "1. Journal"
WHERE type = "daily" AND processed = true AND date < date(today) AND !contains(file.folder, "Processed")
```
