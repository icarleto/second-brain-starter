## All active

Everything currently active, whether or not it has been ranked yet. A project here but missing
from the ranking above is one nobody has decided about.

```dataview
TABLE area AS "Area", file.mtime AS "Touched"
FROM "3. Projects"
WHERE type = "project" AND status = "active"
SORT file.mtime DESC
```

## Open tasks by project

```dataview
TASK
FROM "3. Projects"
WHERE !completed
SORT file.name ASC
```

## Stalled

Active but untouched for three weeks. Close it, or make it the next thing you do.

```dataview
TABLE area AS "Area", file.mtime AS "Last touched"
FROM "3. Projects"
WHERE type = "project" AND status = "active" AND file.mtime < date(today) - dur(21 days)
SORT file.mtime ASC
```

## Done, not yet archived

Finished projects still sitting in the working folder.

```dataview
LIST
FROM "3. Projects"
WHERE type = "project" AND status = "done"
```
