# Second Brain: Roadmap branch

A small, plain text second brain that Claude runs. One system prompt, a PARA folder layout, and five starting Areas for sales development work. Few rules by design: you add more as you need them.

## Use it

You need Claude Desktop and a synced folder (OneDrive, iCloud or similar). Create an empty folder called `Second Brain` inside it. In Claude Desktop, open the **Code** tab, choose **Local**, select that folder and paste this:

```
Set up my second brain in this folder. Do the work yourself rather than
telling me how, and check with me before anything you cannot undo.

1. Download the starter from
   https://github.com/icarleto/second-brain-starter/archive/refs/heads/roadmap.zip
   and unpack its contents directly into this folder, not into a subfolder.
   Delete the zip.
2. This folder does not use git. Delete README.md, .gitignore and every
   .gitkeep file, except keep the empty folders themselves.
3. Tell me in two lines what is now in the folder.
```

Then read `START HERE.md`.

## What is in it

```
.claude/CLAUDE.md   the assistant's whole instructions, short on purpose
00. Inbox           anything new
2. Areas            five starting areas, rename them to yours
3. Projects         one setup project
4. Resources        reference material
5. Meta             how this brain works
99. Archive         done or old
```
