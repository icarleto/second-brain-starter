# What I can teach you

Claude works through this list one item at a time, when an item fits what you are doing. Tick an item when you have used it. Skip any you do not want. The order is a suggestion.

- [ ] **Capture and filing.** Drop anything into `00. Inbox`. Say: `File my Inbox.`
- [ ] **Ask by meaning.** Ask a question about your own notes. Claude finds the right note, answers, and names the note it used.
- [ ] **Check before creating.** Before it makes a new note, Claude looks for an existing one and adds to that instead. No duplicates.
- [ ] **Current state at the top.** A living note opens with what is true now. Older detail moves down, or to `99. Archive`. Say: `Tidy this note.`
- [ ] **Teach the assistant.** `.claude/CLAUDE.md` holds who you are, how you want to be spoken to, and your rules. Say: `Add a rule.`
- [ ] **Limits on acting in the world.** Decide what Claude may never do without asking: spend money, send a message to a real person, sign anything, delete anything. Write each one under "My rules".
- [ ] **Skills.** A job you teach once and reuse, such as "prep me for a call". Say: `Turn what we just did into a skill.`
- [ ] **Personas.** One assistant is enough for most people. If a job wants a different focus or voice, such as a call coach or a copy editor, name a second one and write its short brief in `5. Meta/Personas`.
- [ ] **Record what was done.** A short log of what was done, what is left and what is next. Include what you have settled, so Claude does not ask you again.
- [ ] **Helpers.** For research or a first draft, Claude can hand a piece to a helper that returns text. Claude checks it before anything is filed.
- [ ] **Honest reporting.** Ask Claude to say what it confirmed and what it guessed, and what it did not do. A good habit to add as a rule.
- [ ] **Building something bigger.** Ask whether it should exist at all. Remove steps. Simplify what is left. Make it faster. Automate last.
- [ ] **Refresh this list.** The template improves over time. Say: `Refresh my capabilities list.` Claude fetches the current list from https://raw.githubusercontent.com/icarleto/second-brain-starter/roadmap/5.%20Meta/What%20I%20can%20teach%20you.md and updates only this file, keeping your ticks. It never touches your notes, rules or About me. If the link stops working, ask Isaiah where the template moved.
- [ ] **Scheduled passes.** A task that runs on its own. Add one only after the manual version has run for weeks.
